# M1 科技流动视觉优化验收

日期：2026-11-04。关联：[优化 Issue #10](https://github.com/visibychen/AegisForge/issues/10)。本轮按用户最新范围只优化 M1，M2 暂缓且未开始。

## 变化与协作

Claude 主开发、Codex 审查，沿用同一原生 Claude Session 完成 3 次成功调用。实际交接、发现与核实摘要见 [协作记录](collaboration-2026-11-04.md)。没有新增依赖、外部字体、图片请求或后端功能。

视觉改为近黑/深海蓝控制台、青蓝渐变、细网格与分层边框。内联 SVG 盾牌有轨道、雷达和轮廓流光；能量线和流程导轨提供连续的方向性运动，正文保持静止。风险卡按类别呈现，无虚构计数或分析结果。

顶栏提供可键盘操作的动态效果开关，偏好仅在内存保存。CSS 只有在系统为 no-preference 且页面开关开启时才运行装饰动画；系统 reduce 优先，页面不能绕过。控件可访问名、焦点环和禁用态均作了核对。

## 实际验证

所有 Python 检查均在 Anaconda 的 `AegisForge` 环境（3.13.18）执行。

| 检查 | 结果 |
| --- | --- |
| `conda run -n AegisForge python scripts/check.py` | 通过：pip check、Ruff/格式、20后端测试、6前端测试、TS类型检查和生产构建 |
| Chrome 实际前后端冒烟 | 1项通过：错误/正确令牌、能力边界、令牌清空、键盘动效开关、系统 reduce 不可绕过、恢复动画、手机无溢出 |
| 尺寸核对 | 1440/850/590/390/375/374/360px 均无横向溢出 |
| 手机首屏密度 | 390–360px 的 hero 实测287px，第一轮约524px；盾牌角标未压住标题 |
| 真实运动核对 | 开启时轨道 transform 随时间变化，暂停后保持不变；静态模式无运行中的装饰动画 |
| 键盘与语义 | 可达品牌、工作台、动效开关、令牌输入、显示密码及有效连接按钮；服务连接/工作台可按准确名称定位，无装饰图标英文干扰 |
| 样式核对 | 禁用按钮实际文字色rgb(147,167,191)，虚线边框，仍不可操作；焦点环在短暂过渡后为2px青色且可见 |

E2E 显式设置 no-preference，然后独立测试 reduce 分支并恢复 no-preference，避免测试结果取决于宿主的默认动画设置。没有调用真实模型、执行上传源码或开发 M2。
