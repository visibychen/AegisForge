## 验收命令

在Anaconda AegisForge环境、仓库根目录执行：

```text
python scripts/check.py
python scripts/m6_freeze_guard.py
python scripts/acceptance.py --profile course-delivery-v1
python scripts/acceptance.py
```

课程profile返回0；默认strict仍返回1，用于核对原研究参考目标，不能把它改名当成原目标已经通过。课程profile会重算完整记录/后续成功分母、复核哈希、补充对照、旧模型回归和产品CI文件清单；证据损坏返回2，缺少必要功能/有效性证据返回1。数值目标的达成状态仍在结果中列出，当前profile不会读取它们决定完成与否。
