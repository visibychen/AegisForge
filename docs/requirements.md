# 课程要求与评分映射

核对日期：2026-11-03。来源为用户提供的《课程设计要求.md》和《课程实践报告模板及评分标准（2026秋）.docx》。原始教学文件由用户保留，仓库记录实施所需的要求摘要，不复制原文件及其中的个人信息。

## 功能要求

课程题目为“基于 LLM 的 Web 代码漏洞智能检测与修复工具”。基本功能包括：Web 系统、代码文件/HTTP 请求包上传、特征提取、LLM 分析 XSS/SQL 注入/命令执行等漏洞、展示漏洞类型/风险等级/修复建议。

要求总结将修复功能列为加分项，评分表同时在实现过程与结果分析中明确考察修复代码生成、修复结果验证及修复有效性。因此 AegisForge 将修复及其验证作为必须交付功能，对应 PLAN 的 R05、R06。

## 课程提交物

- Web 端可运行系统、完整实现代码与必要配置。
- 软件工程详细设计，包括模块结构、系统配置、流程、代码设计、数据库概念与逻辑结构、模块详细设计。
- 实现报告，附截图和使用说明，包含实验测试与结果分析。
- 提交前的查重检测报告，查重率低于 15%，随课程报告一起提交。

原模板的正文、层级标题与参考文献规范在 M7 导出报告时按原文件核对。课程截止日期、团队分工及可用模型预算尚未提供，本计划不自行编造；这些信息可以在 M1 排期时补充，不阻塞工程骨架工作。
