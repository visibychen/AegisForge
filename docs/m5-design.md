## 第二阶段实现要点（Claude）

### 移出历史的单一闸门
- `ScanTask.deleted_at` 非空即“不在历史中”。`require_scan`、`require_repair` 把已移出任务及其修复一律当作 404；所有修复入口（创建含幂等复用、详情、历史、下载、验证申请、取消、对比）都经这两个函数。
- 后台同样检查：`ensure_fresh` 把已移出任务视作失效，`claim_repair` 取消属于已移出任务的排队修复（`SCAN_REMOVED`），动态验证 runner 在 `validate_one` 中对已移出任务写入错误记录而不运行容器。
- 删除被拒绝（409 `TASK_ACTIVE`）的条件：检测排队/运行中；任一修复排队/运行中、已申请动态验证、或动态验证处于 pending/running。
- 0006 的 `downgrade` 在存在已移出记录时抛错拒绝，不会让历史“复活”；`ModelCall` 与 Job 记录不动，因此当日预算不会因删除而重置。输入快照因可能被其他任务共享而保留，仍可按编号预览。**本轮不做物理擦除**；可选的后续是只清理快照正文而保留哈希与账务。

### 读取模型
- 总览 `GET /api/v1/workspace`：SQL 聚合（`GROUP BY` + SQLite `json_extract`），只统计每个任务的当前尝试；按“计划模式”区分仅规则 / 模拟 / 真实模型，真实模型另列任务结果；候选修复按状态、模拟、动态验证和验证结论统计（结论最多计算最近 300 个并标注是否截断）。文案不称“确认漏洞”。
- 历史 `GET /api/v1/workspace/history`：状态、编号片段、CWE、等级过滤，偏移分页；每行是轻量摘要（输入名、发现计数、修复计数、分析是否完整），不含凭证与完整结果。
- 发现 `GET /api/v1/scans/{id}/findings`：服务端按 CWE / 等级 / 来源 / 证据状态过滤并分页；`facets` 总是整次尝试的计数，筛选后徽标不会跳动。过滤直接用 JSON 表达式，不增加冗余列。
- 证据 `GET /api/v1/scans/{id}/inputs/{artifact_id}`：只返回属于该（未移出）任务的脱敏文本、HTTP 字段与元数据。
- 对比 `GET /api/v1/repairs/{id}/compare`：只读；仅状态为 `candidate` 时可用（否则 409）；原文与候选都是脱敏文本，另含改动块、基线发现位置和复检后的 persisting / preexisting / introduced 位置。

### 报告（report-2.0）
- 白名单输出：枚举、数字、UUID、哈希、行范围，以及我方常量文字；任何从存储 JSON 读回的字符串仍要通过白名单正则。不含源码、文件名、HTTP 参数名（只保留 `query.0` 这类位置编号）、模型自由文本。
- 内容：任务摘要与模式、分析是否完整、覆盖统计、版本与摘要、各次尝试（当前 / 以往）、发现（带编号与尝试）、修复说明卡（门禁、改动影响、契约摘要、复检增量、动态验证）、局限说明；超过上限时 `truncated` 明确标出。
- Markdown 是真正的表格，单元格仅允许安全字符集，不含代码围栏；文件名 `aegisforge-report-<短UUID>.json|md`，`Cache-Control: no-store`。摘要是完整性记录，不是数字签名。

### 创新：证据导航与对比视图
- `SourceLines`：纯文本逐行渲染（React 文本节点，不解析 HTML），行号 + 文字标签（不只靠颜色），整块可聚焦；↑↓ / PageUp / PageDown / Home / End 移动，N / P 跳到下一处 / 上一处标记，Enter 打开该处发现。
- `EvidenceViewer`：在检测结果中就地定位当前发现（源码行高亮、HTTP 字段定位），可逐条切换；输入按任务与快照缓存；请求用 `AbortController`，过期响应被忽略；404 清除选择，401 提示重新连接。
- `CompareView`：原文与候选并排（窄屏堆叠），原文标出修复目标 / 基线发现 / 改动，候选标出改动与 仍存在 / 原有未修复 / 新增风险。失败候选保留在“本任务的修复记录”中，可随时重新打开。
- `RepairCard`（修复说明卡）：复用门禁账本与执行契约，列出“已检查”与“仍未证明”，明确静态复检与固定测试不证明没有其他漏洞。

### 前端一致性
- 删除事件 `aegisforge:deleted`（带 scanId）使检测面板与修复面板清空选择并清理地址栏；轮询遇 404 立即停止并清除选择，遇 401 停止并通过 `onAuthLost` 让 App 统一丢弃会话，地址栏保留任务编号以便重新连接后恢复。
- `aegisforge:changed` 在任务创建 / 完成、修复候选就绪后触发，总览与历史自动刷新。检测面板不再有重复的“最近任务”，统一由“历史管理与报告”选择任务。
- 所有新请求复用客户端 `request` 的 `ApiError` / 超时 / `AbortSignal`；加载、空状态与错误（含无密钥、无 Docker 的既有提示）均有明确文字。
