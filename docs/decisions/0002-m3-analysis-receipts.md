# ADR 0002：M3 输出来源、覆盖与检测凭证

日期：2026-11-07。状态：已实现，待 PR 集成。关联 #4 / PLAN R03、R04、R07。

真实 DeepSeek 初次响应使用了不合规的来源元数据；同时，合并宽证据区间会吞并独立危险调用，单个 partial 状态无法定位哪些输入未完成分析。两阶段审查与两次第三阶段讨论后，决定如下。

模型只返回严格 wire-1.1 内容，服务端独占 artifact/source/mode/完成性/最终严重性。逐字证据收窄到实际位置，拒绝歧义或伪造；完全链接合并防止一个宽区间串起多个 sink，保留各来源判断。覆盖账本按实际执行记录规则/真实模型/模拟/失败/待处理，不把未运行内容写成已完成。

采用两个 SHA-256 摘要：input_digest 绑定原始内容集合；plan_digest 绑定处理后内容/分块与非秘密分析配置。凭证保存于每次尝试，worker 执行前验证，漂移则停止。复用已有任务详情接口，前端仅下载白名单凭证及覆盖元数据；无新外部依赖、无签名、无额外模型调用。

次数/运行超时等操作限额不参与方案摘要，避免调大日预算就使排队任务失效；总时限在 attempt 首次启动固定并跨租约恢复。模型输出 token 参数会改变实际请求，因此参与摘要。

不采用跨尝试复用成功分块，避免版本差异、旧错误和合并来源被掩盖；重试按当前配置完整重跑，原摘要/凭证/发现保留。配置漂移后重试仍受两次上限约束，Claude 对是否应免费刷新保留异议。M5 可另设计有界免费刷新；M6 可记录供应商返回模型标识的指纹。本版只记录已登记请求模型名，明确滚动服务不能确定性复现。

凭据防护采用完整密钥精确匹配和最终请求体字节检查；发现已知密钥的上传直接拒绝，优先满足用户“仅存环境变量”要求。不把当前密钥写入全局脱敏配置或仓库。已有输入若在轮换后恰好命中，新读取会被拒绝；系统不擅自删除原快照。

代价：最多 8 个分块的元数据，额外本地哈希与迁移；方案变化时需要显式重试。收益：课程报告可追溯输入、参数与覆盖范围，且不会增加付费调用或提前扩展 M4。
