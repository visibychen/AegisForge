# M6 课程交付验收调整（1.13）

2026-11-12，用户明确要求继续完成M6，并允许适当放宽验收标准。调整在本轮补充容器实验之前记录；这是看过旧实验后的课程交付决策，不称为独立科研预注册。

用户进一步明确课程没有硬性数值指标，PLAN中的目标都是项目自设，不必过度关注。原课程评分摘要要求三类漏洞、修复加分功能、实验方案与结果分析，见[课程要求映射](requirements.md)。本次仍展示原参考目标及未达结果；另设`course-delivery-v1`完成工程与实验交付，不把旧失败改成旧目标通过。1.13取代此前1.12收尾建议中仍把85%/15个成功作为硬门槛的部分。

## 调整范围

| 项目 | 原严格口径 | 本轮课程交付口径 |
| --- | --- | --- |
| 真实实验 | 原完整三轮，且要求最终优化后再次完整实验 | 原756任务及54次首次尝试完整保留，作为真实对照实验；不再追加整套付费重跑 |
| 数据独立性 | 新未暴露保留集才能得出最终独立质量结论 | 允许现有已人工复核、已暴露样例作课程回归；明确不能推断独立泛化效果 |
| 最终检测 | 新模型输出上的精确率/召回率等 | 当前静态处理与旧模型记录的事后回归及真实定向结果分开报告；85%等为参考，不作为课程完成门槛 |
| 修复 | 三轮首次≥45/54、每类≥12/18 | 全18个登记样例按固定“最新已安排尝试”规则选取、披露历史尝试；报告实际成功/失败及每类结果，15/18和4/6仅作参考 |
| 安全及业务 | 固定断言真实通过 | 原断言全部保留，另加人工复核Q2–Q4，3个故意部分修复必须被新测试拒绝 |
| 人工复核 | 标注确认 | 接受用户提供的单人逐条复核；保留原件，以新增处置记录解决分歧，不冒充第二人签名 |

上述调整允许工程收尾，不宣称提高原基线成绩或恢复旧保留集的独立性。程序默认严格入口仍保持旧语义，新增课程交付入口必须显式选择新profile并逐项给出证据。M7课程模板报告、查重及最终发布不属于本次M6完成声明。

当前完成条件是：课程功能和三类真实修复演示具备；完整实验记录/失败分析可核对；人工复核分歧有明确处置及补证；安全/业务判据与负对照有效；必要回归和CI通过；部署、性能、资源、兼容及依赖检查有真实证据；报告承认独立性、样本规模及模型限制。覆盖率80%和API p95 500ms也作为分析参考，不能通过修改断言、删失败或编造数据来达标。

## 人工复核处置

Q1采纳“模板注入为主因、XSS为影响”的说明：为SRC-XSS-03族新增独立标注解释，根因CWE-1336、影响CWE-79。历史单标签匹配仍按CWE-79，不改评分；产品目前只支持课程三类，不宣称已全面支持SSTI检测。[CWE-1336](https://cwe.mitre.org/data/definitions/1336.html)说明模板表达式注入可能表现为XSS；[CWE-79](https://cwe.mitre.org/data/definitions/79.html)描述网页输出中的未净化输入。

Q2追加script元素提前终止的浏览器标记载荷；Q3保留display_name并检查email/timezone及未知字段混合请求的原子拒绝；Q4读取固定容器目标`/tmp/m6-backup.sql`检查实际备份内容。新增overlay镜像复用原driver的进程隔离和结果通道，原八个validator文件不改。原36/54、后续诊断11/12及1/1全部保留。

模型预算仍为原1000次，当前992次。本轮优先零模型调用，只有后续确有必要且预先记录定向协议时才可用剩8次；没有追加额度。参考/故意部分修复/模型候选都只能在固定隔离容器内执行。

机器协议见[course-delivery-v1](../evaluation/protocols/m6-course-delivery-v1.json)。新增容器结果和最终验收逐项核对通过前，M6保持进行中。
