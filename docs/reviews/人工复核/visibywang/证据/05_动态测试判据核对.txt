二、共性核对
--------------------------------------------------------------------
1. 编号对应：controlled_repairs.json 18 条、m6_cases.json 18 条、HC IDS 18 条、controls 36 次
   （18 V + 18 S），四者 ID 集合完全一致；m6_cases 的 source_sha256 与 freeze.json test 段一致。
2. 输入可达性：XSS 覆盖 query/path/cookie/json/form；SQLi 覆盖 query 列表/path/JSON/PATCH/header/
   cookie/json；CMDi 覆盖 form/JSON/query/header。每条都对应源码中的真实取值点。
3. 业务预期：全部为精确 JSON、精确数据库值、浏览器文本或命令桩 argv/cwd，不是"状态 200 即通过"。
4. 安全判据：XSS 用浏览器执行标记；SQLi 用状态码或空结果 + 数据库未变；CMDi 用 MARKER 文件 +
   命令桩日志。三者的误报/漏报边界不同，已逐条指出。
5. 功能保留：CMDi 的 observed 检查能阻止"硬编码返回"；SQLi 的数据库检查能阻止"返回成功但没写入"。
6. 已知缺口（本轮 disagree）：h-xss-14 的 </script>、h-sqli-12 的 email/timezone、h-cmdi-09 的
   备份文件内容；另有多条建议项见问题清单第五节。
